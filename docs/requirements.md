# 需求分析与验收清单

## 角色与目标

- 游客：浏览、搜索、分类筛选和查看公开评论/留言。
- 注册用户：维护个人资料，提交评论和留言，获得明确待审反馈。
- 管理员：发布内容、审核社区内容、管理分类/用户/媒体并查看看板。

## 功能需求

1. 文章具备草稿/发布、唯一链接、摘要、正文、封面、分类、发布时间、浏览量。
2. 搜索支持标题和摘要，列表支持最新/热门排序。
3. 评论和留言默认待审，仅审核通过后公开。
4. 富文本编辑器支持自动保存、恢复、预览、字数、封面和离开提醒。
5. 管理端可完成文章、分类、评论、留言、用户和媒体管理。
6. MySQL 持久保存业务数据；Redis 提供会话、限流和排行辅助能力。

## 非功能需求

- 安全：BCrypt、CSRF、HttpOnly 会话、RBAC、XSS 清洗、安全上传和限流。
- 可用性：中文错误、重试/空状态、重复提交保护、响应式和深浅主题。
- 可访问性：WCAG 2.2 AA、键盘操作、200% 重排、reduced-motion。
- 可运维性：Docker 一键部署、健康检查、迁移、备份恢复和日志。
